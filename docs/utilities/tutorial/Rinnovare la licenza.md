# Rinnovare la licenza di Visual Paradigm 11 for E.E.

> **Importante: i file vanno salvati all’esterno di vpworkspace, pena la perdita dei file.**

## Tutorial Windows

### Rinnovo licenza

Per rinnovare la licenza ogni 30 giorni vanno rinominate (o rimosse) due cartelle. Il prof consiglia di rinominare la cartella con .old (non cambia nulla):

```
C:\Users\giuse\OneDrive - University of Pisa\vpworkspace

C:\Users\giuse\AppData\Local\VisualParadigm
```

> La precedente è valida unicamente per Windows

### Aggiornamenti disattivati

Il secondo step da fare, e va fatto una sola volta, è di disattivare gli aggiornamenti automatici, perché potrebbero aggiornare alla versione 12 ma noi dobbiamo usare la versione 11:

```
Tools → Application Options… → Update → Auto Update → Never
```

### Autosave disattivato

Inoltre, è meglio disattivare l’auto save perché genera un sacco di file temporanei che possono dare fastidio:

```
Tools → Application Options… → Project → Auto Save → disabilitato
```
